# Cartoon & Motion Graphics Guidelines Reference

This directory and the `references/` directory hold the complete Bengali authoring and video production guidelines provided for the storyteller skill:

1. **[1-bengali-cartoon-script-writer.md](file:///home/sakib/Downloads/video-generation-skills/references/bengali-cartoon-script-writer.md)**:
   - Bengali scriptwriting prompt & narration structure.
   - Six storytelling phases (হুক, পরিচিতি, সমস্যা, এস্কেলেশন/টুইস্ট, সমাধান, শিক্ষা).
   - Character list table & initial approval gate.
   - ElevenLabs-ready emotion tags (`[laughs]`, `[sighs]`, etc.) & final character specs.

2. **[2-remotion-video-director.md](file:///home/sakib/Downloads/video-generation-skills/references/remotion-video-director.md)**:
   - 2D Motion Graphics & Remotion video production director prompt.
   - 100% full-screen edge-to-edge scenes (no boxed borders or outer margins).
   - Procedural vector characters from text descriptions (no image references).
   - Speech/thought callout bubbles & selective caption rule (zero duplicate text).
   - Clean motion graphics / infographic scenes without characters.
   - Token-efficient 2-point approval workflow & execution commands.

3. **[MASTER-GUIDELINES.md](file:///home/sakib/Downloads/video-generation-skills/references/MASTER-GUIDELINES.md)**:
   - Consolidated master document combining both prompts in full Bengali text.
